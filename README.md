# Arbuz's site

**This site is a place where I show of my projects and talk more about myself. I will also post devlogs on the site!**

# Why I made it
 
I'm a self-taught developer and I mostly build embedded and game stuff. I never wrote a line of HTML before this, so I wanted somewhere to put my projects that wasn't just a list of GitHub repos and a reason to finally learn how the web works.

## What's on it
 
- **About** - who I am and what I'm into 
- **Projects** - what I've built, starting with my ESP32 calculator OS
- **Devlog** - a place where I will post my progress
- **Contact** - how to reach me
